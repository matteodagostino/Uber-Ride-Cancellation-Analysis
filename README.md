# Uber Cancellation — EDA and Modeling

An academic data-science project focused on exploratory data analysis and modeling around ride cancellation behavior.

## Project Goal

The project examines patterns associated with ride cancellations and uses data analysis and modeling to better understand factors related to cancellation outcomes.

## Current Repository Contents

This repository currently contains the submitted project report documenting the exploratory analysis, modeling approach, findings, and conclusions.

## Skills Represented

- Exploratory data analysis
- Data interpretation
- Statistical reasoning
- Modeling
- Communicating findings through a formal report
